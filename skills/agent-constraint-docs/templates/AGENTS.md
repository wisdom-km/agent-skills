## 禁止事项摘要

见 RULES 禁止清单。摘要：不把密钥写入仓库或日志；不绕过门禁；不扩大已确认的范围；不编造测试结果。

## 完成标准

见 RULES 的 DoD。提交前按命令表跑检查，并在 PR 或证据目录留下命令与退出码。

## 何时停下问人

规格冲突；范围变化；缺少必需的 seam；要改门禁；涉及密钥或花费；环境配置本机没有。报告格式：触发 / 停在 / 已读 / 现状 / 提问。
