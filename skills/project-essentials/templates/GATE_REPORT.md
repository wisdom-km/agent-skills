# 门禁表

复制本表，在每个关口填一次。规则见 `project-essentials` 的 MANDATORY.md 第 6 节。贴进 PR 描述，或存到 `docs/evidence/`。

### 门禁 G_（开工 / 任务完成 / 合入 / 发布）· 档位：_（原型 / 曳光弹 / 长期；档位未确认时写「档位未确认，按曳光弹」）· [D] 是 / 否 · [P] 是 / 否

| 编号 | 级别 | 状态 | 证据 |
| --- | --- | --- | --- |
| M-__ | MUST / SHOULD | PASS / FAIL / WAIVED / N/A | 命令和退出码、提交号、文件路径、日志行；WAIVED 写 W-___；N/A 写理由 |
| | | | |

红线：R-1 密钥不进仓库 PASS / FAIL；R-2 真实数据不可逆操作前有备份 PASS / FAIL / N/A；R-3 本表证据都真实可查 PASS / FAIL。

结论：满足 / 未满足（M-__）。
SHOULD 未满足：_（没有就写「无」）
下一步：_（未满足时写补法，并主动提出去做）

填写规则：
- 只列本关口要查的编号（MANDATORY.md 矩阵「关口」列）。
- PASS 没有证据就改成 FAIL。不写「应该没问题」。
- 任一 MUST 是 FAIL，结论只能写「未满足」，不能说完成、不能合入、不能发布。
