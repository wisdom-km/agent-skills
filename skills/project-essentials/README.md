# project-essentials

Use this skill when starting a project, picking one up, or preparing to release it. It lists the software basics every real project needs — version control and rollback, secrets and config, one-command run and README, smoke and regression tests, error handling, data safety, dependency lockfiles, beginner security basics, version numbers and CHANGELOG, health checks and crash reporting — by project tier and by moment.

It also holds `MANDATORY.md`, the single source of mandatory items shared by all skills: M-01 to M-15 with MUST / SHOULD per tier, three non-waivable red lines, four gates (project start, task done, merge, release), the gate table format, and waiver rules.

The agent definition is `SKILL.md`. Each essential has a short file in `essentials/`, and `templates/` holds `.env.example`, `CHANGELOG.md`, `GATE_REPORT.md` (gate table), and `WAIVERS.md` (waiver log).
