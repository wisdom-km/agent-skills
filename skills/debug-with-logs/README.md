# debug-with-logs

Use this skill when something is broken and the cause is not known yet. It walks a beginner through reproducing the bug, finding and reading the logs by request_id, stating a root-cause hypothesis, making a minimal fix, and adding a regression test.

The agent definition is `SKILL.md`. `WORKFLOW.md` is the step-by-step flow, `LOGS.md` shows what a useful log line looks like and where logs live on each platform, and `BUG_REPORT.md` is a copy-paste bug report template.
